# 众包式AI内容核查互动实验

本仓库是互动式仿真平台实验的固定条件入口。

- 研究：Study 1
- 条件：无附注控制组
- 固定条件代码：`control`
- 线上入口：`https://chaoyifan.github.io/crowdcheck-s1-control/`

## 识别策略

所有条件仓库的AI创作、首次声明选择和发布页面完全一致。参与者首次发布时若主动添加AI声明，将正常显示声明并结束体验；只有首次未声明者才会看到本仓库对应的固定处理。条件名称不会出现在参与者界面中。

正式招募时，应由外部问卷或随机分配服务在条件间分配匿名参与者，并通过 `?pid=匿名编号` 传入参与者编号。由于每个仓库只有一个固定条件，不应再通过URL参数改变处理。

## 数据接口

页面完成后会将记录写入当前设备的 `localStorage`，同时向父页面发送 `crowdchecking-experiment-complete` 消息。正式收数必须由问卷平台或研究服务器捕获并持久化该消息；GitHub Pages本身不提供集中式数据库。

## 伦理边界

- 页面为去品牌化学术研究模拟平台，与任何真实社交媒体平台无隶属关系；
- 用户、互动量与社区附注均为虚构材料；
- 页面提示参与者不要输入本人或他人的个人信息。
